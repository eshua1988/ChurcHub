# Church Hub

Самостоятельное PWA-приложение для жизни церкви: люди, отделы, календарь, задачи, объявления и цели служений.

## Первый выпуск

- интерактивная панель обзора;
- ведение людей и отделов;
- календарь событий;
- доска задач по этапам;
- объявления и цели развития;
- автономная работа и установка как PWA.

Данные первого выпуска сохраняются в браузере. Следующим этапом приложение подключается к общей Supabase-базе с Church Account для контролируемого обмена людьми, ролями и группами.

## Локальный запуск

Это статическое приложение: откройте `index.html` через локальный HTTP-сервер, например:

```bash
npx serve .
```
