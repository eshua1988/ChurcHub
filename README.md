# Church Hub

Самостоятельное PWA-приложение для жизни церкви: люди, отделы, календарь, задачи, объявления и цели служений.

## Первый выпуск

- интерактивная панель обзора;
- ведение людей и отделов;
- календарь событий;
- доска задач по этапам;
- объявления и цели развития;
- автономная работа и установка как PWA.

Church Hub использует только Cloudflare: D1 хранит пользователей, комнаты и сообщения, а R2 — вложения комнат.

## Локальный запуск

Это статическое приложение: откройте `index.html` через локальный HTTP-сервер, например:

```bash
npx serve .
```

## Cloudflare

Репозиторий готов к публикации в Cloudflare Workers. Первый запуск автоматически создаёт привязки D1 и R2 для Church Hub, а статические файлы приложения публикуются вместе с Worker.

В GitHub Secrets должны быть заданы:

- `CLOUDFLARE_API_TOKEN` — API Token Cloudflare с правами на Workers, D1 и R2;
- `CLOUDFLARE_ACCOUNT_ID` — идентификатор аккаунта Cloudflare (нужен, если токен видит более одного аккаунта).

После push в `main` откройте **Actions → Deploy Church Hub to Cloudflare**. Адрес Worker появится в журнале шага Deploy. Проверка развёртывания: `https://<worker>/api/health`.

Первый зарегистрированный пользователь становится администратором нового Church Hub. Внешние базы данных не используются.
